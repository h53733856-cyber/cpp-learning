# 左值、右值、左值引用、右值引用

## 左值

左值可以先理解为：**代表一个持续存在的对象，并且通常可以通过名字找到它**。例如：

```cpp
int a = 10;
```

这里的 `a` 是左值，因为 `a` 代表一个实际存在的对象，可以继续访问和修改：

```cpp
a = 20;
```

注意：左值不等于“出现在等号左边”。例如：

```cpp
int b = a;
```

这里 `a` 虽然出现在等号右边，但 `a` 仍然是左值。

## 右值

右值可以先理解为：**临时产生的值，通常是马上要被使用或销毁的对象或计算结果**。例如：

```cpp
10
a + 10
std::string("hello")
```

其中 `10` 是一个临时值，`a + 10` 是计算产生的临时结果，`std::string("hello")` 是一个临时创建的 `string` 对象，它们都是右值。

括号不会改变值类别，例如：

```cpp
a + 10      // 右值
(a + 10)    // 仍然是右值
```

## 左值引用 vs 右值引用

```cpp
int&  r1 = a;    // 左值引用，可以绑定左值
int&& r2 = 10;   // 右值引用，可以绑定右值
```

可以先简单理解为：

```text
左值 → 左值引用 T&
右值 → 右值引用 T&&
```

右值引用的重要意义是：**让 C++ 能识别一个对象是临时的、可以考虑把它的资源转移走，而不是重新复制一份。**

例如 `std::string` 内部通常管理着一块动态内存：

```text
s1 → [一大块动态内存]
```

如果复制 `s1`：

```text
s1 → [一大块动态内存]

s2 → [重新申请一块内存]
      ↑
      复制 s1 的内容
```

但如果源对象是一个马上要销毁的临时对象，就没有必要再复制一份，可以直接把资源转移给目标对象：

```text
临时对象 → [一大块动态内存]
                ↓
              资源转移
                ↓
           s2 → [原来的内存]
```

这就是移动语义的核心思想。

# std::move

`std::move` **不是把对象真的移动了**，它主要是把一个表达式转换成右值，从而允许后面的操作把这个对象当成可以移动的对象。

例如：

```cpp
std::string s1 = "hello";
std::string s2 = std::move(s1);
```

这里真正执行移动的是 `std::string` 的**移动构造函数**。`std::move(s1)` 相当于告诉后面的代码：`s1` 接下来可以被当成右值处理，可以考虑把它内部的资源转移出去。

所以一定要区分：

```text
std::move()
→ 改变表达式的值类别，使其可以参与移动

移动构造 / 移动赋值
→ 真正执行资源转移
```

单独执行：

```cpp
std::string s1 = "hello";
std::move(s1);
std::cout << s1;
```

`std::move(s1)` 本身没有真正移动任何东西。只有当它参与某个需要右值的操作时，才可能触发移动，例如：

```cpp
std::string s2 = std::move(s1);
```

## 移动之后的源对象

执行：

```cpp
std::string s2 = std::move(s1);
```

之后，`s1` **仍然可以使用**，但它处于**有效但状态未指定**的状态。因此不能依赖 `s1` 仍然保存原来的 `"hello"`。不要把“移动后对象不能使用”当成规则。

可以简单记成：

```text
移动后：
源对象仍然有效
但不要依赖它原来的值
```

# 移动构造

移动构造函数的形式：

```cpp
class MyString {
public:
    char* data;

    MyString(const MyString& other) {
        // 拷贝资源
    }

    MyString(MyString&& other) {
        // 移动资源
    }
};
```

`MyString(const MyString& other)` 是**拷贝构造**，接收左值，通常需要复制资源；`MyString(MyString&& other)` 是**移动构造**，接收右值，可以直接转移资源。

例如：

```cpp
MyString a;

MyString b = a;             // 拷贝构造
MyString c = std::move(a);  // 移动构造
```

拷贝通常需要重新申请资源并复制内容，而移动通常可以直接把 `a` 管理的资源交给 `c`，因此对于管理大量动态资源的对象，移动通常可以避免昂贵的资源复制。

# 移动构造 vs 移动赋值

关键区别是：**目标对象之前是否已经存在。**

```cpp
A b = std::move(a);
```

这里 `b` 原本不存在，需要创建 `b`，所以是**移动构造**。

而：

```cpp
A b;
b = std::move(a);
```

这里 `b` 已经存在，只是把 `a` 的资源转移给已有的 `b`，所以是**移动赋值**。

完整对应关系：

```text
                     左值                  右值
对象不存在        拷贝构造              移动构造
对象已经存在      拷贝赋值              移动赋值

拷贝构造：A(const A&)
移动构造：A(A&&)

拷贝赋值：A& operator=(const A&)
移动赋值：A& operator=(A&&)
```

因此看到代码时，可以先判断两个问题：

```text
① 目标对象之前存在吗？
   不存在 → 构造
   已存在 → 赋值

② 源对象是左值还是右值？
   左值 → 拷贝
   右值 → 移动
```

例如：

```cpp
A a;

A b = a;             // 左值 + 对象不存在 → 拷贝构造
A c = std::move(a);  // 右值 + 对象不存在 → 移动构造

A d;
d = a;               // 左值 + 对象已存在 → 拷贝赋值
d = std::move(a);    // 右值 + 对象已存在 → 移动赋值
```

**移动语义的核心不是“把对象搬走”，而是“把对象管理的资源转移给另一个对象”。** 对于管理动态内存、文件句柄等资源的类型，这种资源转移可以避免昂贵的复制。
